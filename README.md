Spotify Web Player Clone

A responsive, pixel-perfect UI clone of the Spotify Web Player built purely with **HTML5** and **CSS3**. 

This project was created to practice modern web design layouts, flexbox structures, custom scrolling behaviors, and replicating complex user interfaces from popular web applications without relying on external UI frameworks or JavaScript libraries.

## ✨ Features

- **Sidebar Navigation:** Includes home, search, library, badge prompts, and footer legal/privacy navigation items.
- **Main Content Layout:** Divided into structured sections such as *Recently Played*, *Trending Now*, and *Featured Charts* with music card layouts.
- **Bottom Playback Controller:** Custom music player bar complete with track metadata placeholders, control icons (play, pause, skip, shuffle), and a styled duration slider.
- **Pure CSS Styling:** Leverages Flexbox, CSS variables, custom scrollbars, and media styling to mirror Spotify's dark-mode aesthetic.
- **Clean Folder Structure:** Well-organized separation of HTML document structure and asset management.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure for accessibility and page layout.
- **CSS3:** Custom styles, layout structuring using Flexbox/Grid, hover states, and font/icon integrations.
- **FontAwesome / Google Fonts:** Icons and typography to match the Spotify look and feel.
